# مستخرج بيانات الوثائق (نسخة البرنامج)

برنامج بيشتغل على جهازك: بتدوس عليه فتفتح الواجهة في المتصفح، والقراءة بتتم جوه جهازك بمحرك EasyOCR
(أقوى من Tesseract في العربي). الصورة مبتتبعتش لأي إنترنت.

## الاستخدام بعد البناء
1. شغّل `DocExtractor.exe` (هتفتح نافذة سودا، سيبها مفتوحة).
2. المتصفح هيفتح لوحده على `http://127.0.0.1:8765`.
3. ارفع الصورة، لفّها لو محتاجة، واضغط **استخراج البيانات** (10 لـ 40 ثانية على CPU).
4. لإيقاف البرنامج اقفل النافذة السودا.

## إزاي تعمل ملف الـ exe (من غير ما تثبّت بايثون على جهازك)
**الطريقة الأسهل: GitHub (بيبني على سيرفر مجاني)**
1. اعمل حساب على github.com وأنشئ Repository خاص (Private) جديد.
2. ارفع محتويات الفولدر ده كله (بما فيهم فولدر `.github`).
3. من تبويب **Actions** اختار **Build Windows exe** ثم **Run workflow**.
4. بعد ما يخلص (حوالي 15-25 دقيقة) نزّل الملف الناتج `DocExtractor-windows` من نفس الصفحة وفكّه.

**طريقة تانية:** على أي جهاز ويندوز عليه Python 3.10-3.12 (مؤقتًا للبناء بس) شغّل `build_exe.bat`.
الناتج في `dist\DocExtractor\DocExtractor.exe` وتقدر تنقل الفولدر كله لأي جهاز، ومش محتاج بايثون ولا إنترنت.

> حجم الفولدر الناتج كبير (حوالي 1 جيجا تقريبًا) لأنه شايل محرك الذكاء الاصطناعي والنماذج جواه.

## للتجربة بدون exe
```
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements.txt
python server.py
```
أول تشغيل بيحمّل النماذج من النت (حوالي 100 ميجا).

## لو النتيجة مش مظبوطة
شغّل بـ `python server.py --debug` (أو اضبط `DOCX_DEBUG=1`)، هيحفظ آخر قراءة خام في `last_ocr_debug.json`
جنب البرنامج، تقدر تبعتهولي (بعد ما تشيل أي بيانات حساسة) وأضبط التحليل على شكل وثائقك بالظبط.
الملف ده بيتكتب من جديد في كل قراءة ومش بيتحفظ إلا في وضع `--debug`.
